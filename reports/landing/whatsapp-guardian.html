How it works: User messages 'START' to Guardian's WhatsApp Business number → Bot replies with OAuth link to connect their WhatsApp Business Account → User approves permissions → Bot confirms connection, asks which group to monitor → User shares group invite link or ID → Bot runs first scan, sends risk report + backup confirmation → Daily scans run automatically; alerts and reports delivered via chat.
